One in five people turn over every year. This is what that does to a hospital system.

Cedar Fork Health is a fictional regional health system with three hospitals, a clinic network and about 5,000 employees. Its HR data, from hire to paycheck to help-desk ticket, is generated, governed and queryable by an AI agent. Pick a fiscal year and a workforce group; every number below follows.

    Ask the data, safely

    Every number on this page also comes from an AI agent's toolkit. The agent answers questions in plain English by calling the same metric functions the dashboard uses, and it works inside the guardrails a regulated employer would require.

    1. Question“Why did nursing turnover spike in FY25?”
    2. Claude decideswhich tools to call, and in what order
    3. Tools run14 curated metric tools, plus guarded read-only SQL
    4. Every call is auditedappended to a log with inputs, outcome and timing
    5. Answerbuilt only from tool results, with definitions

    Guardrails

    • Read-only. The database opens in read-only mode, and an authorizer refuses writes, schema changes and attachments.
    • No PII. Names, email and birth year are blocked at the column level, even inside SELECT *.
    • Bounded. One statement per call, 200-row cap, five-second timeout, eight tool rounds per question.
    • Evaluated. 12 eval cases check the tools against independent SQL on every push, and the same cases grade the agent's full answers.
